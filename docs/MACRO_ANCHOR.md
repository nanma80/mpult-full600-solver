# Where to click when applying the macros

MPUlt 1.55 has **two default views**, depending on how you enter the puzzle. Both cases use the same macro reference point shown below. These screenshots were supplied by the user and are preserved unchanged.

## 1. Selecting the puzzle or starting the app

**Selecting the full 600-cell from the puzzle menu, or starting the app with this puzzle automatically loaded:** the white cell is already at the front, centered in the view. The reference point is directly clickable; no view adjustment is needed.

![White cell centered, with the macro reference point marked in red](../assets/reference/macro_anchor.png)

Locate the white cell's central horizontal edge. When applying a macro, use the spot marked in red: on the white cell, just above that edge and slightly to the left. The red mark is an annotation in this screenshot, not a marker supplied by MPUlt.

## 2. Opening a `.log` file

**Opening a `.log` file** gives a different default view: the white cell is initially out of sight.

![Default viewpoint immediately after opening a log, before dragging](../assets/reference/log_start_view.png)

From this view, **hold the right mouse button and drag downward a little** until the white cell emerges from behind the camera and comes into view. This brings you to the view shown in the first screenshot above. Use that screenshot to locate the same red-marked reference point before applying the macros. Sticker colors may differ from these examples.

## Applying the macros

Use the same geometric reference point for every separate macro step. Match the cell and face geometry rather than a fixed screen coordinate; the camera position, window size and sticker colors may differ. Apply either the separate solution steps in order or the combined entry once, following the output README.

Future production output folders include local copies named `macro_anchor.png` and `log_start_view.png`, so the instructions do not depend on this project folder or temporary clipboard images.
